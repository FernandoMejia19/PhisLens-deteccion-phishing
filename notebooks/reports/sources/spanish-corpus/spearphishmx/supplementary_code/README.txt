SpearPhishMX supplementary code (public release)

This folder contains a minimal script to reproduce descriptive summaries and
basic quality checks reported in the companion Data in Brief data article.

Files:
- spearphishmx_qc_summary.py : reads the public CSV and generates summaries
- requirements.txt           : minimal Python dependency

Note:
This code operates on the PUBLIC release (sanitized bodies, defanged URLs).
It does not recreate the original raw emails.
